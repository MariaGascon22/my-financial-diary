# My Financial Diary

Diario financiero personal. Funciona como app (PWA): se puede instalar en el celular o la computadora y abre sin internet.

## Dónde se guardan los datos
Todo se guarda **en el navegador de cada dispositivo** (localStorage). No se sube a ningún servidor ni a este repositorio.
Para pasar tus datos a otro dispositivo o a esta nueva dirección: en la app anterior usa **Exportar JSON** y aquí **Importar backup**.

## Publicar en GitHub Pages
1. Sube estos archivos a la raíz del repositorio.
2. Settings → Pages → Deploy from a branch → main → / (root).
